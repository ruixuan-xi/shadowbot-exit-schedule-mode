# 影刀：一键退出调度模式

> 按一个快捷键，**先停掉正在运行的任务，再退出调度模式**。

---

## 一、整体思路

```
按下快捷键
      │
      ①  检查本机状态：当前是不是调度模式？有没有任务在跑？
      │
      ②  有任务 → 调用云端接口把它停掉
      │      没有任务 → 直接跳过
      │
      ③  切回普通模式，并确认真的切换成功
```

之所以要先停任务，是因为**任务正在运行时，影刀不允许切换模式**。所以顺序必须是「先停、后切」。

---

## 二、准备工作：确认影刀 CLI 可用

这个工具依赖影刀的官方命令行工具 `shadowbot.shell-cli.exe`。

关于影刀 CLI 的说明、安装与使用方式，请以官方文档为准：

> **[《影刀技能（CLI版）》](https://www.yingdao.com/yddoc/rpa/zh-CN/958294294025375744)**

开始之前，请确认两件事：

| 前提 | 说明 |
|---|---|
| 影刀客户端版本较新 | 旧版本可能不含 CLI 组件，详见上方官方文档 |
| 客户端**已登录**企业账号 | 未登录时命令行会被拒绝执行 |

### 怎么确认已经就绪

按 `Win + R`，输入 `cmd` 回车，然后执行：

```
shadowbot.shell-cli.exe system health
```

看到 `"status": "ready"` 就说明一切正常，可以继续下面的步骤。

### 如果提示「不是内部或外部命令」

先到影刀安装目录看一眼有没有这个文件：

```
C:\Program Files\ShadowBot\
C:\Program Files (x86)\ShadowBot\
D:\Program Files\ShadowBot\
```

| 情况 | 怎么办 |
|---|---|
| 目录里有 `shadowbot.shell-cli.exe` | **什么都不用做**。本工具会自动找到它，不依赖环境变量 |
| 目录里没有这个文件 | 当前客户端不含 CLI 组件，请按上方官方文档处理 |

> 提示「未登录 / 登录已失效」的话，打开影刀客户端重新登录一次就行。

## 三、开始使用（3 步）

### 第 1 步：放文件

把整个文件夹拷到电脑上任意位置，例如：

```
C:\ShadowBot-Tools\exit-schedule-mode\
```

文件夹里的文件**不要拆开**，必须放在一起。

### 第 2 步：填密钥

用企业管理员账号登录影刀控制台：

> **控制台 → 调度中心 → API 执行（API 配置）→ 新增**

> 部分版本路径是：**高级设置 → API KEY 管理 → 创建 API KEY**

1. 点「新增」，系统名称随便填，例如 `退出调度工具`
2. 确定后会生成两个值：`accessKeyId`、`accessKeySecret`
3. 复制，填进文件夹里的 `config.txt`：

```
accessKeyId=这里粘贴accessKeyId
accessKeySecret=这里粘贴accessKeySecret
```

⚠️ 等号两边**不要加空格**，值也**不要加引号**，粘贴时别带上多余空格。

> 同一对密钥可以给多台电脑共用，不用每台单独建。

### 第 3 步：设快捷键

在文件夹里按住 **Shift + 右键** →「在此处打开 PowerShell 窗口」，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\create-shortcut.ps1
```

执行完，桌面会多一个「退出影刀调度模式」，快捷键是 **Ctrl + Alt + D**。

想换成别的键，比如 `Ctrl+Alt+S`：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\create-shortcut.ps1 -Hotkey "Ctrl+Alt+S"
```

**也可以手动设**：

1. 右键 `exit-schedule-mode.bat` → 发送到 → 桌面快捷方式
2. 右键桌面上的快捷方式 → 属性
3. 在「快捷键」框里点一下，按下你要的组合键（如 `Ctrl+Alt+D`）
4. 确定

## 四、用起来是什么样

**平时按快捷键就行**——窗口在后台一闪而过，跑完自动关闭，成功时不会有任何打扰。

| 当时的情况 | 结果 |
|---|---|
| 本来就没在调度模式 | 提示「无需退出」，窗口自动关闭 |
| 在调度模式、没有任务在跑 | 几秒后退出调度模式，窗口自动关闭 |
| 在调度模式、有任务在跑 | 先把任务停掉，再退出调度模式，窗口自动关闭 |
| 任务停不掉 | **弹窗提示**，告诉你下一步怎么办 |

> 如果你双击 `exit-schedule-mode.bat` 手动运行，能看到完整执行过程（成功 3 秒后窗口自动关闭）。
> 万一失败，窗口会留着不关，方便你看清楚原因。

## 五、常见问题

**Q：按了快捷键没反应？**
- 检查桌面上的快捷方式还在不在（快捷键是绑在快捷方式上的，删了就失效）
- 这个组合键可能被别的软件占用了，换一个试试
- 注销重新登录一次，让系统重新注册快捷键

**Q：为什么不能「暂停」？**
影刀没有「暂停任务并退出调度」这种状态——退出调度意味着这台机器人从控制台下线，跑着的任务会被判定为异常。所以只能「停止」，不能「暂停后继续」。

**Q：换一台电脑要重新弄吗？**
把文件夹拷过去，重新填一次 `config.txt` 的密钥、重新建一次快捷方式就行。其他都不用改。

## 六、文件说明

| 文件 | 说明 |
|---|---|
| `exit-schedule-mode.bat` | 快捷键指向的就是它 |
| `exit-schedule-mode.ps1` | 实际执行的逻辑，不用管 |
| `create-shortcut.ps1` | 用来创建桌面快捷方式和快捷键 |
| `config.txt` | 存放密钥，**需要你填** |
